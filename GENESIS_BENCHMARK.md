# GENESIS / HQ200K — Doom benchmark R02

Use only a scaled derivative of Garyu-tt/mikoshi-hq500m. HQ500M is a synthetic human-inspired topology, not a measured human connectome. Build 200,000 resident simulated neurons, not virtual IDs. Retain the original seven regions, proportions, 1024-cell local module pattern (with explicitly handled partial modules), 24 local and 8 projected potential edges per source, region routing, inhibitory polarity and weight rules. Proposed rounded proportional populations: cortex 90000, cerebellum 28000, hippocampus 20000, thalamus 20000, basal ganglia 16000, brainstem 14000, limbic 12000. Record any departures, source commit, graph hash, actual edge counts and neural parameters.

Keep upstream trainer, UDP protocol, scenarios and reward configuration. The transport is not a neural runtime. A separate HQ200K factory must construct and verify the graph and expose metadata(), stimulate(), feedback(), event(), close(). Factory signature: factory(topology_path, neurons, seed). Metadata: architecture="HQ200K", regions=7, resident_neurons=200000, topology_sha256 (hash of materialized topology). The topology argument identifies the validated HQ200K graph, not a 500M virtual address table. Stimulation receives frequencies_hz, amplitudes_ua, groups, artifact_wait_ms, collect_window_ms; return eight nonnegative integral spike counts from neural state. Feedback receives kind, channels, frequency_hz, amplitude_ua, pulses, unpredictable, event_name. Define units, channel mapping, timing and plasticity explicitly.

Disable hardcoded sensory-to-action BRIDGES and external Q action scoring for the scientific arm. Preserve the HQ500M dynamics where practical and document any added local reward-modulated synaptic plasticity as an experimental change. No fake backend, privileged game state, or silently substituted topology.

Start with a bounded 100-step CPU smoke test on an isolated research node, then compare upstream 10 Hz, 50 ms artifact wait and 50 ms collection timing, same scenario/WAD, observations, reward, seeds and training budgets. Run random spike, zero spike, degree-matched shuffled topology and plasticity-off controls; also freeze encoder/readout in a separate experiment. Record raw logs, graph counts, hashes, spike counts, plasticity, reward, CPU time and peak RAM. No quantitative claim versus CL1 until comparable biological measurements are available.
