## CPU runtime R02
The included hq200k_backend.py implements 200K resident cells and 6.4M directed slots (duplicates/self-links may exist). Local modules are aligned within each scaled region. It uses the original HQ leak/threshold/refractory and weight scale with 10 ms virtual ticks, 32 disjoint sampled cells per electrode, 0.1% random spontaneous drive per tick, and experimental reward-modulated local causal eligibility (100 ms). These choices are synthetic and not calibrated to CL1. No hardcoded motor bridges or Q action policy. Input uses only the eight encoding channels and one pulse (upstream burst_count=1); frequency magnitude is not resolved within a single pulse. Feedback is scheduled in virtual time; unpredictable flags and real electrical waveform are not modeled. The fixed electrode sampling spans all regions and may not convey sufficient signals; measure against zero/random controls before interpreting performance.

Run in an isolated CPU environment:
    python -m pip install numpy
    python -m unittest -v test_genesis_neural_interface test_hq200k_backend
    python genesis_neural_interface.py --backend hq200k_backend:factory --topology hq200k_config.json --seed 37421 --max-steps 100

The upstream training process is separate and requires its game/ML dependencies. CI covers graph construction and packet-level calls, not a real game episode. No live Doom metrics or biological comparison yet. Do not merge before integration and QA.

Sources: https://github.com/Garyu-tt/mikoshi-hq500m and https://github.com/SeanCole02/doom-neuron .

## Actual game integration smoke (R03)
Run `python hq200k_doom_smoke.py --arm structured --batches 2 --output smoke-structured` with the upstream dependencies (CPU PyTorch, ViZDoom, TensorBoard and OpenCV). It uses upstream PPOTrainer and actual progressive_deathmatch WAD; the original scenario timeout is shortened to 128 game tics for this integration check. Two batches, 32 steps minimum each, 10 Hz. It checks for real UDP replies and rejects silent zero fallbacks. Five arms: structured, plasticity frozen, degree-matched shuffled, zero decoder input, and independent Poisson(1) decoder input. In the last two arms the actual network still runs for transport telemetry. No matched biological data, no inference about learning or CL1 superiority from this short run. The upstream encoder includes privileged scalar game features; those are unchanged for protocol comparability, not a pixels-only test. Outputs are raw spike arrays, episode metrics, model configuration and timing/resource telemetry. CI: HQ200K real Doom smoke. Run with no production credentials or host access.
